# Materials

В эту папку можно положить локальные материалы для RAG:

- `.txt`
- `.md`
- `.pdf`

На основе этих файлов бот строит RAG-контекст и использует релевантные фрагменты при ответах на вопросы.

Реальные личные, учебные или закрытые материалы не рекомендуется публиковать в GitHub. По умолчанию содержимое этой папки игнорируется через `.gitignore`, кроме этого поясняющего файла.
