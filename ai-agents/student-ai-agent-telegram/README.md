# Telegram AI-агент для студента МИЭТ

Telegram-бот на Python, который отвечает на сообщения пользователя через LLM-агента, умеет вызывать инструменты и использовать локальные учебные материалы как RAG-контекст.

## Возможности

- Ответы через LLM с OpenRouter и LangChain.
- Tool calling: модель сама выбирает нужный инструмент.
- Расписание МИЭТ для выбранной группы на сегодня или завтра.
- Подбор вакансий по ML, AI и Data Science через API hh.ru.
- Ссылки на разделы Профи.ру для поиска заказов.
- RAG по файлам из папки `materials`: `.txt`, `.md`, `.pdf`.
- Локальный векторный индекс ChromaDB.
- Память диалога: окно последних сообщений и краткое резюме старой части беседы.

## Стек технологий

- Python 3
- Telegram Bot API
- LangChain
- OpenRouter API
- ChromaDB
- Hugging Face Sentence Transformers
- requests

Локально также могут появляться:

- `.env` — настоящие токены и настройки, не публикуется.

- реальные файлы в `materials/` — личные или учебные материалы, по умолчанию не публикуются.

## Установка

1. Создать и активировать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Создать файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

4. Заполнить `.env` своими значениями:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
OPENROUTER_API_KEY=your_openrouter_api_key
MIET_GROUP=ИКТ-42
MIET_WEEK_OFFSET=0
```

## Запуск

```bash
python3 agent.py
```

После запуска бот сбрасывает webhook и начинает получать сообщения через long polling.

- `Объясни тему из лекции про сети`

## Материалы для RAG

В папку `materials/` можно положить локальные `.txt`, `.md` и `.pdf` файлы. При первом запросе бот загрузит материалы, разобьет их на фрагменты и построит локальный индекс ChromaDB в папке `chroma_db/`.

Если материалы изменились, удалите локальную папку `chroma_db/` и перезапустите бота, чтобы индекс пересобрался.

## Безопасность

- `.env` не должен попадать в GitHub: в нем находятся токены Telegram и OpenRouter.
- `chroma_db/` не нужно публиковать: это локально сгенерированный индекс.
- Реальные учебные, личные или закрытые материалы из `materials/` не рекомендуется публиковать в GitHub.
- В репозиторий стоит добавлять только безопасные примеры или поясняющие файлы.
